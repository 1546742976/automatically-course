# 学习通本地课程助手

在 Windows 本机运行的 Electron 应用，将学习通网站嵌入助手窗口。登录后可以筛选课程、安排队列、查看章节，并处理已适配的视频、音频、文档阅读及部分练习。

应用保存本机登录会话、AI 设置和队列进度。重新打开后，由你点击开始或继续队列。

## 选择启动方式

| 方式 | 适用场景 | 环境要求 |
| --- | --- | --- |
| Windows x64 便携版 | 直接使用助手 | 完整便携 ZIP，无需 Node.js/npm |
| 源码版 | 开发、调试或自行构建 | Windows、Node.js 22.12+、npm |

便携版附带 Electron 和运行依赖，启动时无需下载运行环境。学习通网站和 AI 接口仍需联网。仓库源码不包含构建产物；没有便携 ZIP 时，请按下方步骤自行构建。

## 使用便携版

1. 将 `course-assistant-0.5.8-win-x64.zip` 完整解压到可写文件夹。
2. 双击文件夹中的 **学习通助手.exe**。
3. 点击「连接学习通 / 登录」，在内嵌页面完成登录，返回课程队列。
4. 点击「刷新课程列表」，选择学期和课程，再点击「将所选课程加入队列」。
5. 确认队列顺序和播放设置，点击「开始 / 继续队列」。

EXE 必须与 `resources`、`locales`、DLL 等配套文件一起保留。请先解压再运行，复制应用时复制整个文件夹。

暂停后可以调整队列顺序或移除课程。「只处理当前章节」用于当前打开的章节；「在助手内查看课程」可返回课程页面。遇到人工验证时，按提示在网站内处理后再继续。

## 从源码启动

安装 [Node.js](https://nodejs.org/) 22.12 或更新版本，取得源码后，在项目根目录运行：

```powershell
npm ci
npm start
```

也可以双击项目根目录的 **启动学习通助手.cmd**。启动预检会检查 Node.js、依赖及 Electron 运行程序：依赖缺失时安装依赖，Electron 包存在但运行程序不完整时单独补齐并校验下载。首次安装需要联网。

源码启动后，登录和课程操作与便携版相同。

## 登录状态和 API Key

### 下次打开还要登录吗？

助手使用持久化浏览器会话，在本机保留学习通 Cookie 和网站存储。从同一数据目录重启后，可以继续使用尚未过期的登录状态。应用没有单独保存、自动填写学习通明文账号密码的功能。

平台使会话过期、主动退出账号或删除浏览器资料后，需要重新登录。「连接学习通 / 登录」按钮也用于打开已登录的个人空间，按钮名称不代表登录状态丢失。

### 配置 AI 接口

展开「DeepSeek 解题设置」，填写接口根地址、模型名称和 API Key，点击「保存 AI 设置」。密钥保存在当前数据目录的 `ai.json` 中。再次打开显示「已配置，留空保留」时，无需重新填写。也可在启动进程中通过 `DEEPSEEK_API_KEY` 环境变量提供密钥。

`ai.json` 中的 API Key 为明文，请将数据目录作为私人资料保管。启用 AI 解题后，题干、选项及截图识题所需的题目图片会发送至配置的接口。受支持的练习会填写并自动提交；AI 答案可能有误，使用前请确认设置和课程要求。

## 数据位置、备份与更新

| 启动方式 | 数据目录 |
| --- | --- |
| 源码版 | 项目根目录的 `.local-data/` |
| 便携版 | EXE 所在目录的 `.local-data/` |

两个版本默认使用各自的数据目录。切换版本后没有显示旧队列或密钥时，请先检查是否使用了另一份 `.local-data/`。便携版的数据位置不受启动时工作目录影响。

备份、更新或从源码版迁移到便携版时：

1. 正常关闭助手，等待进程退出。
2. 备份原来的整个 `.local-data/`。
3. 将完整新版解压到新文件夹，复制备份的数据目录到新版 EXE 旁。
4. 启动新版，检查登录状态、AI 配置和课程队列。

不要让多个助手进程同时使用同一份浏览器资料。浏览器登录资料能否跨电脑沿用取决于平台及系统保护机制，迁移后可能需要重新登录。

`.local-data/` 已被 Git 忽略，包含登录资料、密钥和个人学习记录，请勿加入提交或公开分享。忽略规则不会移除已经跟踪的文件，提交前仍需检查变更。

## 功能与适用范围

- 按学期筛选课程，默认按北京时间匹配当前学期。
- 按队列逐门处理课程，保存章节位置，切换前关闭上一门课程页。
- 支持视频、音频、部分文档阅读器和练习题型，可设置播放速度、静音及自动切换。
- 检测到平台验证、多终端提示或未适配任务时，显示提示或暂停等待处理。

学校、课程和网站页面布局可能不同，任务完成情况与成绩以学习通平台记录为准。助手不能保证所有题型、阅读器或课程页面都受支持。

## 开发、测试与构建

当前锁定 Electron `44.9.0`、Playwright `1.64.1` 和 electron-builder `26.18.0`，安装时使用仓库 lockfile。

```powershell
# 源码语法检查
npm run check

# 本地模拟课程测试，无需真实账号
npm test

# 在 Windows x64 上构建便携版
npm run build:win
```

构建输出：

```text
dist/
├── win-unpacked/
│   ├── 学习通助手.exe
│   └── …配套运行文件
└── course-assistant-0.5.8-win-x64.zip
```

发布包包含应用资源和运行依赖，采用 `asar: false`；打包白名单排除本机数据、测试输出和仓库元数据。当前提供便携 ZIP，不提供安装器、自动更新或代码签名。

### 便携版验收

使用单独的、没有个人资料的解压目录。脚本会写入模拟队列和配置，请勿指向日常使用的数据目录。

```powershell
node scripts/verify-portable.cjs "E:\便携版验收\win-unpacked"

# 额外联网检查真实学习通登录页
node scripts/verify-portable.cjs "E:\便携版验收\win-unpacked" --online
```

脚本检查移除 Node.js/npm PATH、阻断依赖下载后的启动，以及内嵌页面、模拟队列、重启恢复和进程退出。`--online` 只打开真实登录页，不验证真实账号登录后的课程功能。报告和截图写入 `test-results/`。

### 项目目录

```text
local/          应用入口、内嵌窗口、控制面板和课程处理逻辑
scripts/        构建、测试、运行目录修复与便携版验收
tests/          自动化测试
.local-data/    源码版私人资料与应用临时文件（不提交）
.cache/         下载、构建及测试缓存（不提交）
dist/           便携应用和 ZIP（不提交）
test-results/   验证报告、日志和截图（不提交）
```

Electron 运行程序位于 `node_modules/electron/dist/`。项目启动和构建脚本将 Electron、打包工具及 npm 缓存定向到 `.cache/`，应用临时文件位于对应的 `.local-data/tmp/`。系统安装的 Node.js 等共享工具保持原位置。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 源码版提示缺少 Node.js | 安装 Node.js 22.12+，或使用完整便携版。 |
| Electron 包已安装，但提示运行程序缺失 | 重新运行 `npm start`，预检会单独补齐运行程序。 |
| 下载失败或 `fetch failed` | 检查网络和代理。预检优先使用显式代理环境配置，否则读取 Windows 已启用的静态代理；PAC 需提供显式代理地址。配置仅传给安装子进程。 |
| EXE 无法运行或目录不可写 | 完整解压到可写目录，保留配套文件。项目开发环境可运行 `npm run repair:runtime` 后重试。 |
| 重启后队列或密钥消失 | 检查源码版与便携版是否使用不同的数据目录，按迁移步骤复制资料。 |
| 每次都要重新输入 API Key | 点击「保存 AI 设置」，确认显示「已配置，留空保留」；检查数据目录是否可写。 |
| 登录失效 | 打开学习通重新登录；不要删除 `.local-data/desktop-profile/`。 |

`repair:runtime` 仅修复项目生成的 Electron 和便携输出目录权限及 Medium 完整性标签，保持浏览器沙箱开启。源码双击启动及便携版的错误日志位于各自 `.local-data/startup.log`，提示窗口会指出位置。反馈问题时请隐藏密钥、Cookie 和私人资料。
