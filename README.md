# 学习通本地课程助手

本地程序只显示一个课程助手窗口，学习通网页直接内嵌其中。登录、输入、复制粘贴和滚动由真实网页响应，课程在后台继续运行。无需安装浏览器扩展，无需服务器。

## 启动

本机需要 **Node.js 22.12 或更新版本**。程序自带 Electron 浏览器，首次安装会下载运行环境；从旧版迁移登录状态时会读取原 Chrome / Edge 资料。

1. 双击项目根目录的 **启动学习通助手.cmd**。首次运行自动安装依赖。
2. 在助手中点击「连接学习通 / 登录」，在内嵌网页中扫码或输入登录信息，完成后点击右上角「返回课程队列」。
3. 点击「刷新课程列表」，默认匹配当前学期；也可切换其他学期或「全部学期」。搜索并勾选多门课程，点击「将所选课程加入队列」。
4. 选择同时处理 1 / 2 / 3 门课程（默认 2 门）、速度与静音，然后点击「开始 / 继续队列」。暂停后可用 ↑ / ↓ 调整课程顺序，或移除课程。
5. 运行期间保持电脑唤醒和联网。点「暂停」会停止全部任务和受控视频；关闭助手窗口会退出程序。下次启动保留课程队列和章节位置，点击继续后恢复。

旧版助手的登录 Cookie 和网页本地资料会自动迁移，课程队列与 API Key 沿用原设置。登录失效时，在助手内重新登录即可。双击启动脚本后不会保留命令行窗口；启动错误记录在 `.local-data/startup.log`。

也可以在项目目录运行：

```powershell
npm install
npm start
```

## 功能与范围

- 多课程队列按列表顺序补充空位，默认最多 2 门课程并行；每门课内部按章节顺序处理，一次播放一个媒体。课程完成、需处理原因和暂停位置分别保存。
- 平台提示「多终端登录」时自动停止并行，关闭旧课程页后按原顺序单门继续，面板显示原因并保存单门设置；单门仍出现同样提示则暂停并显示平台原话，待其他正在学习该账号的页面或设备关闭后继续。
- 队列遇到未适配内容或加载错误时记下原因，接续其他课程；验证码、身份验证或登录失效会暂停全部课程，处理后点继续。
- 单门队列启动或接续课程时关闭其他未运行的学习通页面，避免已停止课程继续发送后台会话请求；保留章节位置，点击「打开课程」可重新进入。页面中尚未提交的手动输入不会随关闭保存。
- 学期选项读取自学习通，按北京时间和学年匹配当前学期（9 月至次年 1 月为第一学期，2 月至 8 月为第二学期）。没有匹配项时显示全部课程并提示，可手动切换。切换筛选会保留已勾选和已入队的其他学期课程。
- 「在助手内查看课程」打开全窗口网页区域，支持原生中文输入、复制粘贴、滚动、拖动和 80% / 100% / 125% / 150% 缩放。顶部标签切换页面，网页弹出的新页面会成为内嵌标签。
- 课程安排中的「打开课程」可直接查看对应课程；页面已跳回首页时，会从课程入口返回保存的章节。已经在对应课程内时保留当前页面和位置。右上角「返回课程队列」收起网页，后台课程继续运行。
- 默认 1 倍速静音播放，可选择 1.25 / 1.5 / 2 倍速。
- 检测学习通嵌套 iframe 中的视频，同一课程一次播放一个视频，结束后接续其他视频。
- 本页已识别任务全部处理后，通过网页按钮切换下一节；刷新及同一课程内的章节跳转后继续。
- 当前章节目录明确显示「已完成」且没有待完成任务点时，直接通过下一节按钮继续，不再答题、提交或重复播放阅读。仅检查与当前章节地址一致的活动目录项；其他章节的完成标记不作为跳过依据，验证码及自动切换开关仍生效。
- 学习通任务卡片明确显示「暂无内容」的空章节可通过下一节按钮继续；未识别内容仍停留检查。
- 课程页无可见验证而跳回首页时，自动从课程入口恢复保存章节一次；仍然跳转则仅暂停该课程并保留页面。实际出现验证码、身份验证或登录失效时暂停全部课程。
- 状态面板显示播放进度；普通暂停后自动恢复，超过 45 秒无进展时提示检查。
- 音频通过网页播放器正常播放；支持 `.imglook` 图片式 PPT/PDF 翻页及已适配图文阅读容器的逐屏滚动，每页至少等待 5 秒。阅读器未适配时显示提示。
- 文字章节练习支持单选、多选、判断、填空、简答：DeepSeek 解题 → 校验完整性和选项 → 填写 → 提交 → 检查网页成功标记。
- 练习显示截图采集进度，再按每批最多 10 题依次解答，显示已取得答案数量；空值或缺题仅补答一轮未解决题目。仍不确定时显示具体题号及已解决数量，整份练习保持未填写、未提交。
- 关闭截图识题时的图片／公式题、未知题型、缺失答案、未载入任务、未知任务、验证码、登录及人脸验证会提示处理。不会随机填答案，也不会重复点击提交。
- 点击「扫描当前章节任务」可以读取当前已展开的任务名称、类型和题目数量。扫描仅限当前章节，不自动遍历整门课程。
- 单课程模式可展开「直接打开课程网址」，在助手内进入章节后点击「只处理当前章节」。手动离开正在处理的课程时停止该课程。
- 使用播放器正常播放和网页导航。学习通是否记录任务完成，以课程页面为准。
- 当前适配 `*.chaoxing.com` 的 `/mycourse/studentstudy` 章节页。学校定制域名或新版页面可能需要补充适配。

## 本机数据

项目源码位于 `local/`，测试位于 `tests/`；`package-lock.json` 随源码提交，保证依赖版本可复现。`node_modules/` 为本机安装的依赖，其中 Electron 浏览器占用数百 MB，可通过 `npm ci` 重新安装。`releases/` 存放本机打包文件；`test-results/` 为测试截图和临时资料，均不提交 Git。

浏览器访问课程会产生缓存，可能达到数百 MB。关闭助手后，可以删除 `.local-data/desktop-profile/` 及其 `Partitions/*/` 下的 `Cache`、`Code Cache`、`GPUCache`、`ShaderCache`、`GrShaderCache`、`DawnGraphiteCache`、`DawnWebGPUCache` 等缓存目录。保留其余浏览器资料以及 `.local-data` 中的配置文件，以继续使用现有登录、Key 和课程进度。旧版 `browser-profile`、`assistant-profile` 在确认迁移成功后可移除。

`.local-data/desktop-profile` 保存内嵌浏览器资料，课程与助手界面使用独立会话；`.local-data/preferences.json` 保存播放设置、并行数量、学期筛选、课程队列和章节位置。迁移记录与网页本地资料也保存在 `.local-data`。它们已加入 `.gitignore`，不随项目打包。不要把浏览器资料目录分享给其他人。

浏览器运行时不要同时启动第二个助手。

## DeepSeek Flash

打开控制面板中的「DeepSeek 解题设置」，填入 API Key 并保存。官方默认根地址为 `https://api.deepseek.com`，模型为 `deepseek-flash`，也支持自行填写兼容接口和模型。参考 [DeepSeek 官方文档](https://api-docs.deepseek.com/)。

密钥保存在被忽略的 `.local-data/ai.json`，不会返回到状态面板或打包分享；也可通过 `DEEPSEEK_API_KEY` 环境变量提供。留空保存会保留已有密钥。开始处理任务后，题干、选项及题型会发送到配置的 AI 服务；图片、公式或特殊字体题启用截图识题时，会同时发送该题的截图，并自动填写和提交答案；AI 答案可能有误。

此版本基于公开页面结构和模拟课程适配，学校定制页面可能存在不同布局。文档翻到末页或看到提交成功不等同于已被学校计入成绩，任务完成状态以学习通页面为准。未配置密钥时，视频和文档仍可运行，遇到练习会提示配置。

截图识题默认开启。DeepSeek Flash 官方支持图片输入；其他兼容服务若不支持图片，请关闭此选项，遇到需要截图的题目时程序会停止并提示。特殊字体题按网页真实渲染截图解读，不使用乱码题干猜测。

本机验证：已登录后查看《大学生法律风险防范与化解》的章节目录和第一章测试（38 题），确认自定义选项、单选／判断识别及特殊字体截图；使用已配置的 DeepSeek Flash 完成一道截图题的接口校验，未提交该份真实练习。0.5.0 的 28 项测试通过；0.5.1 已通过跳转误报、真实可见验证与练习流程的相关回归测试。真实账号读到 49 门课程，默认匹配到 2026–2027 第一学期的 13 门课程。

真实视频页面需要通过播放按钮初始化签名媒体源，助手已适配 Video.js 播放按钮，并排除章节页无源、隐藏的翻译音频。已验证助手自动启动首讲视频并持续增加播放进度，识别时长为 18 分 06 秒。0.5.3 通过真实队列确认：教材为 428 页，能逐屏阅读；该账号并行时收到学习通的多终端登录提示，单门视频持续 55 秒未再跳转。0.5.4 已验证一份 38 题真实测验的自动填写、确认提交和接续下一节视频；平台最终记录结果以学习通为准。
